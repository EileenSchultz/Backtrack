# 🧩 Backtrack Visualizer | Визуализация алгоритма перестановок

![C#](https://img.shields.io/badge/C%23-239120?style=for-the-badge&logo=c-sharp&logoColor=white)
![.NET](https://img.shields.io/badge/.NET-512BD4?style=for-the-badge&logo=dotnet&logoColor=white)
![WPF](https://img.shields.io/badge/WPF-0078D7?style=for-the-badge&logo=windows&logoColor=white)

Интерактивное десктопное приложение для наглядной визуализации работы алгоритма **перебора с возвратом (Backtracking)** на примере генерации всех возможных перестановок чисел.

Проект позволяет в реальном времени увидеть, как алгоритм "выбирает" элементы, "исследует" ветку рекурсии и "отменяет" свой выбор (возвращается назад), если зашел в тупик.

---

## ✨ Основные возможности (Features)

*   **🎬 Пошаговая анимация:** Наглядное отображение текущей собираемой перестановки и массива неиспользованных чисел.
*   **⏸️ Управление процессом:** Возможность поставить анимацию на паузу (кнопка «Стоп») и продолжить с того же места, не теряя уже найденные результаты.
*   **🚀 Оптимизация памяти:** Использование `yield return` (ленивая генерация) позволяет алгоритму работать с большими числами (до N=12) без риска переполнения оперативной памяти (`OutOfMemoryException`).
*   **⚙️ Динамическая скорость:** Программа автоматически адаптирует скорость анимации в зависимости от введенного числа N, чтобы пользователю не приходилось ждать вечность.

## 📂 Структура проекта

Проект разделен на логические части (разделение UI и бизнес-логики):

*   📄 **`MainWindow.xaml`** — Файл разметки интерфейса. Содержит панель управления (ввод N, кнопки), области для визуализации массивов и список результатов.
*   📄 **`MainWindow.xaml.cs`** — Code-behind логика окна. Отвечает за работу `DispatcherTimer` (анимацию), обновление UI и обработку нажатий кнопок.
*   📄 **`PermutationsBacktrack.cs`** — "Сердце" программы. Чистый алгоритм бэктрекинга, который генерирует шаги в виде последовательности `StepInfo` с помощью итераторов. Не зависит от UI.

## 🚀 Как пользоваться

1. Запустите приложение.
2. Введите число **N** (количество элементов для перестановки) в текстовое поле. Допустимый диапазон: **от 1 до 12**.
3. Нажмите кнопку **«Запустить»**.
4. Наблюдайте за процессом:
   * **Серые квадраты** в верхнем ряду — числа, которые уже использованы на текущем шаге.
   * **Синие квадраты** — текущая собираемая перестановка.
   * В правом нижнем углу будут появляться готовые комбинации.
5. В любой момент нажмите **«Стоп»**, чтобы поставить алгоритм на паузу. Нажмите **«Продолжить»**, чтобы вернуться к работе.

## ⚠️ Важные нюансы и ограничения

Из-за комбинаторного взрыва (количество перестановок равно N!), визуализация имеет свои особенности:

*   **Для N от 1 до 7:** Анимация идет медленно и подробно. Каждая найденная перестановка добавляется в правый список, чтобы вы могли ее увидеть.
*   **Для N от 8 до 12:** Алгоритм начинает работать **очень быстро**. Чтобы интерфейс программы не завис (так как для N=12 нужно найти 479 миллионов комбинаций!), вывод каждой перестановки в список отключается. Вместо этого программа просто показывает **счетчик** найденных перестановок в реальном времени. При этом визуализация текущего шага (синие и серые квадратики) продолжает работать.
*   **Остановка для больших N:** Вы можете нажать «Стоп» даже на числе 12, и все результаты, которые алгоритм успел насчитать до этого момента, сохранятся на экране.

## 💻 Как запустить проект локально

Если вы разработчик и хотите собрать проект самостоятельно:

1. Установите [.NET SDK](https://dotnet.microsoft.com/download) (версии 8.0 или выше).
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/EileenSchultz/Backtrack.git
3. Перейдите в папку с проектом и запустите:
  dotnet run
4. Сборка в один .exe файл
  Чтобы получить готовый к запуску на любом ПК файл, выполните в терминале:
  dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
Готовый .exe файл появится в папке bin\Release\netX.0-windows\win-x64\publish\.
